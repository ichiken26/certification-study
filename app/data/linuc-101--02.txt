# 1.01 インストール・仮想化 / コンテナ基本操作
docker ps -a|Dockerで稼働中・停止中のすべてのコンテナを一覧表示したい。|docker ps -aは停止済みコンテナも表示する。
docker images|ローカルに保存されているDockerイメージを一覧表示したい。|イメージとタグ等の一覧を表示する。コンテナ一覧とは別。
docker pull nginx|レジストリからnginxイメージをローカルへ取得したい。|pullはイメージを取得する。
docker stop app|稼働中のコンテナappに通常の停止を要求したい。|停止シグナルを送り、猶予時間後には強制停止する。
# 1.01 インストール・仮想化 / 起動ターゲット
multi-user.target|systemdでGUIを使わない通常のマルチユーザーシステムを起動するターゲットは？|ネットワークや一般サービスを含む非GUIの起動状態。
graphical.target|systemdでGUIのログイン画面を含む通常起動を目標にするターゲットは？|multi-user.target等に依存しGUIの起動を含む。
rescue.target|systemdで基本的なシステムとローカルファイルシステムを準備し、管理用シェルを提供する復旧ターゲットは？|rescueモードは基本環境を起動する。通常のマルチユーザーサービスは起動しない。
emergency.target|systemdで可能な限り最小限の環境を起動し、他のファイルシステムを通常は自動マウントしない復旧ターゲットは？|emergencyモードはrescueより最小限のシェル環境。
# 1.01 インストール・仮想化 / シグナル
SIGTERM (15)|killコマンドでシグナル指定を省略した場合の既定のシグナルは？|プロセスへの通常終了要求。捕捉可能。
SIGKILL (9)|プロセスが捕捉・無視できない終了シグナルは？|カーネルがプロセスを終了させる。
SIGSTOP|プロセスを終了せず、捕捉・無視できない方法で実行停止させるシグナルは？|SIGSTOPにより停止状態になる。
SIGCONT|停止中プロセスの実行を再開するシグナルは？|停止状態から再開させる。
SIGHUP|端末の切断時などに送信され、デーモンによっては設定再読み込みに利用されるシグナルは？|Hangupシグナル。処理内容はプログラム依存。
# 1.01 インストール・仮想化 / 接続
ssh user@server|リモートサーバーに暗号化されたシェル接続を確立したい。|SSHによるリモートログイン。
scp file user@server:/tmp/|ローカルファイルfileをSSHを利用してリモートの/tmpへコピーしたい。|scpはSSHベースのファイル転送コマンド。
exit|現在のシェルから終了し、リモートログイン中なら通常そのセッションを終了したい。|exitはシェルの終了を指示する。
who|現在ログインしているユーザーや端末を一覧確認したい。|whoは現在のログインセッション情報を表示する。
# 1.02 ファイル管理 / 権限の読み取り
rw-r-----|通常ファイルのモード640を記号形式の9文字で表したものは？|所有者rw、グループr、その他なし。
rwxr-x---|通常ファイルのモード750を記号形式の9文字で表したものは？|所有者rwx、グループr-x、その他なし。
rw-r--r--|通常ファイルのモード644を記号形式の9文字で表したものは？|所有者rw、グループとその他r。
rwx------|通常ファイルのモード700を記号形式の9文字で表したものは？|所有者のみrwx。
# 1.02 ファイル管理 / 所有権の操作
chmod g+w file|ファイルの既存権限を維持してグループの書込権限を追加したい。|記号形式のg+wはgroupへのwrite追加。
chmod o-r file|既存権限を維持してその他ユーザーの読み取り権限だけ削除したい。|o-rはothersのreadビットを削除する。
chmod a+x file|所有者・グループ・その他の全区分に実行権限を追加したい。|aはall、+xは実行権限の追加。
chown -R alice:dev dir|dirとその配下の所有者をalice、所有グループをdevに変更したい。|chownの-Rは再帰的に所有権を変更する。
# 1.02 ファイル管理 / ディレクトリの権限
検索権限 (x)|ディレクトリの中の既知の名前のファイルへパスをたどるために必要なディレクトリ権限は？|ディレクトリのxは検索・通過権限。内容の一覧表示はrも必要。
読み取り権限 (r)|ディレクトリ内の名前の一覧を読み取るための権限ビットは？|ディレクトリのrはエントリ名の読み取り。
書き込みと検索権限 (w+x)|通常のディレクトリで、内部のファイルを削除・作成するために必要なディレクトリ権限の組み合わせは？|ディレクトリのエントリを変更するにはwとxが必要。sticky bit等の追加制約にも注意。
sticky bit|共有ディレクトリの書込権限を持つ利用者でも他者所有ファイルの削除を制限するビットは？|通常、ファイル所有者やディレクトリ所有者等だけが削除・改名できる。
# 1.02 ファイル管理 / ファイル操作
cp -i a b|既存のbを上書きする前に確認を求めてコピーしたい。|-iは対話的確認。
cp -r src dst|ディレクトリsrcを再帰的にコピーしたい。|-rは配下を含めコピーする。
mv -n a b|既存のbを上書きせずに移動したい。|-nは既存宛先を上書きしない。
ls -la|隠しファイルを含め長形式でディレクトリ内容を表示したい。|-lは詳細表示、-aはドットで始まる名前も含める。
# 1.02 ファイル管理 / 検索
find /tmp -type f|/tmp以下の通常ファイルだけを検索したい。|-type fは通常ファイルを指定する。
find /tmp -mtime +7|/tmp配下で最終更新から経過した24時間単位の切捨て値が7を超えるファイル等を検索したい。|-mtime +7は24時間単位で8以上経過した対象を選ぶ。
find /tmp -size +10M|/tmp配下でGNU findのMiB単位の丸めサイズが10を超えるファイル等を探したい。|-size +10Mはサイズが10MiBを超える対象を選ぶ。
find /tmp -user alice|/tmp配下で所有ユーザーがaliceのファイル等を検索したい。|-userは所有ユーザーを条件とする。
# 1.02 ファイル管理 / 擬似ファイルシステム
/proc|プロセスやカーネルの動的情報を擬似ファイルとして公開する代表的ディレクトリは？|procfsには/proc/PIDや/proc/cpuinfo等が存在する。
/sys|デバイスやドライバー等のカーネルオブジェクト情報をsysfsとして公開する場所は？|sysfsはカーネルのデバイスモデルをユーザー空間へ公開する。
/dev|デバイスファイルを格納する代表的ディレクトリは？|ブロック・キャラクターデバイス等をファイルとして扱う。
/run|起動後のランタイム状態やPIDファイル等を格納する代表的ディレクトリは？|通常は起動時に作成される揮発性のランタイムデータ。
# 1.03 GNU・Unix / テキスト表示
cat file|小さなファイルの内容をそのまま標準出力へ連結出力したい。|catはファイルを順に読み出し標準出力へ書く。
less file|大きなテキストをページ送り・検索しながら閲覧したい。|lessはページャー。全内容を一度に端末へ出力しない。
nl file|ファイルの各行に行番号を付けて表示したい。|nlは既定で空でない本文行等に番号を付ける。
od -x file|バイナリファイルの内容を16進数の短整数単位でダンプしたい。|odの-xは16進表示形式の1つ。
# 1.03 GNU・Unix / grep
grep -i error file|大文字小文字を区別せずerrorを含む行を抽出したい。|-iは大文字小文字を区別しない。
grep -v error file|errorに一致しない行だけを抽出したい。|-vはマッチの反転。
grep -n error file|errorに一致する行と行番号を表示したい。|-nは各一致行に行番号を付ける。
grep -c error file|errorに一致した行の数を表示したい。|-cは一致した行数。1行中の一致回数とは異なる。
grep -E 'foo+' file|拡張正規表現を用いてfooの最後のoが1回以上繰り返すパターンを検索したい。|-EはEREを使用する。
grep -F 'a.b' file|ピリオドをワイルドカードではなく文字としてa.bを検索したい。|-Fは固定文字列検索。
# 1.03 GNU・Unix / sortとwc
sort -n file|数字が文字列ではなく数値として小さい順に並ぶようにソートしたい。|-nで数値順になる。
sort -r file|通常の照合順序の逆順にソートしたい。|-rは比較結果を反転する。
sort -u file|行をソートし、同じ比較キーの重複を1行にまとめたい。|-uは同値の行の出力を1件にする。
wc -c file|ファイルのバイト数を数えたい。|-cはバイト数。文字数は-m。
wc -w file|テキスト中の単語数を数えたい。|-wは空白等で区切られた単語を数える。
# 1.03 GNU・Unix / アーカイブ
tar -cf archive.tar dir|圧縮せずディレクトリdirをtarアーカイブにまとめたい。|-cは作成、-fはアーカイブ名。
tar -tf archive.tar|tarアーカイブを展開せず中身の一覧を確認したい。|-tはアーカイブの一覧。
tar -xf archive.tar|tarアーカイブを展開したい。|-xは展開。
tar -xzf archive.tar.gz|gzip圧縮されたtarアーカイブを展開する明示的なコマンドは？|-xで展開、-zでgzip処理、-fでファイル指定。
# 1.03 GNU・Unix / 圧縮
gzip file|単一ファイルをgzipで圧縮し、通常file.gzへ置き換えたい。|gzipはファイルをgzip形式で圧縮する。
gunzip file.gz|gzip圧縮ファイルを展開したい。|gunzipはgzip形式を復号・展開する。
bzip2 file|単一ファイルをbzip2方式で圧縮したい。|通常は拡張子.bz2になる。

# 1.03 GNU・Unix / vi編集
yy|viのノーマルモードで現在の1行をヤンク（コピー）したい。|yyは行単位でヤンクする。
p|viのノーマルモードでヤンク済みの内容をカーソル後方へ貼り付けたい。|pはput。行単位なら通常カーソル行の下に挿入する。

G|viのノーマルモードで引数なしでファイル末尾へ移動するキーは？|Gは指定行へ移動し、行番号なしなら最終行。

# 1.04 パッケージ / RPM応用

# 1.05 ハードウェア・FS / fstab

# 1.05 ハードウェア・FS / カーネル情報
/proc/cpuinfo|CPUのモデルやフラグをテキストで確認したい。|procfsが公開するCPU情報。
/proc/meminfo|システム全体のメモリやキャッシュ、スワップの詳細情報を確認するprocfsファイルは？|メモリ関連の統計を公開する。
/proc/interrupts|割り込み番号ごとのCPU別発生回数等を確認したい。|割り込み統計を表示する。
/proc/mounts|現在のプロセスのマウント名前空間におけるマウント一覧をprocfsから確認したい。|現在のマウント情報を取得できる。
