# 01 アプリ設計 / 実行環境
Cloud Run services|HTTPコンテナをマネージド実行しリビジョン単位でトラフィックを分割したい。|サービスとリビジョンでHTTPワークロードを運用する。
Cloud Run jobs|HTTP待ち受け不要の一括コンテナ処理をタスク単位で実行したい。|実行が完了すると終了するジョブ機能。
GKE Autopilot|Kubernetes APIを使いつつノード管理をGoogleに任せたい。|Autopilotではノード等の管理が自動化される。
Artifact Registry|ビルドしたコンテナイメージや言語パッケージを保管したい。|アーティファクトのマネージドリポジトリ。
# 02 非同期処理 / イベント
Pub/Sub|発行者と複数の購読者を疎結合にし、イベントを非同期で配送したい。|トピックとサブスクリプションを用いたメッセージング。
Cloud Tasks|HTTPタスクを指定レートで実行し、失敗時に再試行させたい。|タスクキューで配送先、実行レート、再試行を管理する。
Eventarc|Cloud Storageなどの対応イベントをCloud Runのサービスへルーティングしたい。|CloudEventsベースのイベント配送を提供する。
Workflows|複数のGoogle Cloud APIやHTTP処理を順序・分岐・再試行付きで実行したい。|宣言的なワークフローを管理する。
# 03 アクセス制御 / 認証
Application Default Credentials|Google Cloudクライアントライブラリで実行環境に応じた認証情報を自動取得したい。|ADCの探索順により環境変数、ローカル認証、実行環境ID等を利用する。
サービスアカウントの偽装|許可を持つ開発者が短期トークンで対象サービスアカウントとして操作したい。|サービスアカウントの権限を一時的に利用する。Token Creator等の適切な権限が必要。
Secret Manager|アプリの機密設定をバージョン管理し、IAMで取得を制御したい。|シークレット値の管理サービス。
Identity-Aware Proxy|社内向けアプリへの利用者認証・認可をGoogleの前段プロキシで行いたい。|認証済み利用者に対してIAM等のポリシーを評価する。
# 04 デプロイ・監視 / 運用
Cloud Build|コミットからコンテナを自動ビルド・テストしたい。|ビルドのステップとトリガーを管理する。
Cloud Deploy|GKEやCloud Runへのリリースを環境間で段階的に昇格させたい。|マネージド継続的デリバリーを提供する。
Cloud Trace|リクエストが複数サービスを通過する際の処理時間を分散トレースしたい。|トレースとスパンでレイテンシを可視化する。
Error Reporting|ログ等に含まれる例外をグループ化して発生件数を把握したい。|アプリのエラーを集約し通知等に利用する。
