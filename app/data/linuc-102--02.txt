# 1.06 シェル・スクリプト / シェルの結果
5|Bashで echo $((2+3)) を実行すると何が出力されるか？|算術展開により2+3=5。
6|Bashで echo $((2*3)) を実行すると何が出力されるか？|算術展開により2×3=6。
2|Bashで echo $((8%3)) を実行すると何が出力されるか？|剰余演算。8を3で割った余りは2。
3|Bashで echo $((7/2)) を実行すると何が出力されるか？|Bashの通常の算術演算は整数。7/2は3。
# 1.06 シェル・スクリプト / 条件判定
test "$a" = "$b"|Bashで変数aとbの文字列が等しいか判定したい。|testの=は文字列比較。両変数を引用符で囲む。
test "$a" -gt "$b"|Bashで整数aが整数bより大きいか判定したい。|-gtはgreater than。
test "$a" -lt "$b"|Bashで整数aが整数bより小さいか判定したい。|-ltはless than。
test "$a" -ne "$b"|Bashで整数aと整数bが等しくないか判定したい。|-neはnot equal。
# 1.06 シェル・スクリプト / 実行制御
command1 && command2|command1が終了ステータス0のときだけcommand2を実行したい。|&&は左側成功時のみ右側を実行するANDリスト。
;;|Bashのcase文で各パターン節の終端に用いる記号は？|;;はcase節の終了。通常のコマンド列の区切りには単一の;を使う。
command1 ; command2|command1の終了ステータスに関係なく、その終了後にcommand2を実行したい。|セミコロンでコマンドを順次実行する。
command1 &|command1をバックグラウンドで起動しシェルが待機しないようにしたい。|&は非同期リストを作る。
