# 01 データ準備 / 機械学習基礎
訓練データ|モデルパラメータを学習させるために使用するデータの分割は？|学習アルゴリズムがパラメータを最適化するためのデータ。
検証データ|訓練後のモデルやハイパーパラメータの選択に利用し、最終評価データとは分けるものは？|検証セットでモデル選択や調整を行う。
テストデータ|モデル選択完了後、未使用データに対する最終的な性能評価に用いるデータは？|最終評価まで学習・調整に利用しないことが重要。
データリーク|学習時に本番予測時点では利用できない未来の情報が特徴量へ混入する現象は？|評価性能が実運用より過大に見積もられる要因。
# 02 モデル開発 / 評価
Precision|陽性と予測したサンプルのうち実際に陽性の割合は？|TP/(TP+FP)。適合率。
Recall|実際の陽性サンプルのうち陽性と正しく予測した割合は？|TP/(TP+FN)。再現率。
F1|PrecisionとRecallの調和平均は？|2×Precision×Recall/(Precision+Recall)。
RMSE|回帰予測の誤差を二乗して平均し、平方根を取った指標は？|元の目的変数と同じ単位の誤差指標。
# 02 モデル開発 / SageMaker
SageMaker Training Job|カスタムコンテナや対応アルゴリズムを用いてマネージドなモデル学習を実行したい。|学習用コンピュートを確保してトレーニングを実行する。
SageMaker Processing Job|学習前の特徴量生成やモデル評価コードを独立したマネージドジョブで実行したい。|データ前処理・後処理などの処理ジョブを実行する。
SageMaker Model Registry|学習済みモデルをバージョン管理し、承認ステータスやメタデータを記録したい。|モデルパッケージの登録・管理を行う。
SageMaker Automatic Model Tuning|ハイパーパラメータの組み合わせを探索して目的メトリクスを最適化したい。|複数のトレーニングジョブを実行して最適な設定を探索する。
# 03 デプロイ・監視 / 推論
リアルタイム推論エンドポイント|低遅延で同期的な予測APIを継続提供したい。|常時または対応する容量設定のエンドポイントで推論リクエストを処理する。
Batch Transform|S3に保存された大量の入力データを一括推論し、結果をS3に保存したい。|オンラインのエンドポイントを常時稼働させずバッチ推論する。
Asynchronous Inference|処理時間が長いリクエストをキューイングし、結果を後から取得するSageMaker推論方式は？|非同期推論で大きな入力や長時間処理に対応する。
Model Monitor|デプロイ済みモデルの入力データ品質等を継続監視し、基準との差異を検出したい。|モデル監視のためのデータ収集や品質分析を支援する。
