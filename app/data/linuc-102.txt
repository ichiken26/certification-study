# 1.06 シェル・スクリプト / 環境変数
export NAME=value|変数NAMEを子プロセスにも引き継がせたい。|exportで環境変数としてマークする。単なる代入はシェル内部の変数。
unset NAME|シェル変数NAMEの定義を解除したい。|unsetは変数や関数の定義を解除する。
alias ll='ls -l'|現在のシェルでllをls -lの短縮名として定義したい。|aliasはシェルのコマンド別名を定義する。
source ~/.bashrc|現在のBashで変更した.bashrcを再起動せず読み込みたい。|sourceまたはドットコマンドは現在のシェルでファイルを実行する。
# 1.06 シェル・スクリプト / 設定ファイル
~/.bashrc|対話型の非ログインBashを起動するたびに個人のエイリアスを設定したい。|対話型非ログインBashが読み込むユーザー設定ファイル。
~/.bash_profile|ログインBashで個人の初期化を実行したい。存在すれば.bash_loginや.profileより優先されるファイルは？|Bashはログイン時に候補を順に探し、最初の読み取り可能なものを実行する。
/etc/profile|ログインシェルでシステム全体の初期化を行う標準的なファイルは？|ログインシェルの全体の環境設定に利用される。
~/.bash_logout|ログインBashの終了時に個人の処理を実行するファイルは？|ログインシェルの終了時に読み込まれる。
# 1.06 シェル・スクリプト / 特殊変数
$?|直前のコマンドの終了ステータスを取得したい。|0は通常成功、非0は失敗等。意味はコマンドごとに異なる。
$#|シェルスクリプトへ渡された位置引数の個数を取得したい。|引数の数。スクリプト名は含まない。
$1|スクリプトに渡された最初の引数を取得したい。|第1位置引数。$0はスクリプト名等。
"$@"|引数に空白が含まれても元の引数境界を保ったまま別コマンドへ渡したい。|二重引用符付きの$@は各位置引数を独立した引数に展開する。
$$|通常のBashで現在のシェルのPIDを取得する変数は？|シェルのPID。サブシェル等ではBASHPIDと異なる場合がある。
# 1.06 シェル・スクリプト / 条件判定
test -f file|fileが存在し通常ファイルであるか判定したい。|testの-fは通常ファイル判定。ディレクトリは対象外。
test -d dir|dirが存在しディレクトリであるか判定したい。|-dはディレクトリ判定。
test -x file|現在のユーザーがfileを実行可能か検査したい。|-xは実行権限を検査する。ディレクトリなら検索権限。
test -z "$name"|変数nameの文字列長が0か検査したい。|-zは空文字列判定。クォートで引数分割を防ぐ。
test "$n" -eq 10|変数nの整数値が10に等しいか検査したい。|-eqは整数比較。文字列比較の=とは異なる。
# 1.06 シェル・スクリプト / 展開
"$name"|変数nameを展開しつつ、空白による引数分割やパス名展開を防ぎたい。|二重引用符内では変数展開を行うが、通常の単語分割・グロブを防ぐ。
'$name'|ドル記号を含む文字列$nameをそのまま渡したい。|一重引用符内では変数展開を行わない。
$(date)|dateの標準出力を文字列として利用したい。|コマンド置換。末尾の改行は除去される。
$((2 + 3))|Bashの算術展開で2と3の加算結果を取得したい。|算術式を評価して数値を展開する。
# 1.06 シェル・スクリプト / 制御
for x in a b; do echo "$x"; done|a、bの各値について処理を繰り返す構文は？|forはリストの各要素を変数へ代入して反復する。
while test -f flag; do sleep 1; done|flagが通常ファイルとして存在する間、繰り返し待機する構文は？|whileは条件コマンドが成功する間ループする。
if test -f flag; then echo OK; fi|flagが通常ファイルの場合だけOKを出力する構文は？|ifは条件コマンドの終了ステータスに応じて分岐する。
case "$x" in a) echo A;; esac|文字列xをパターンに照合して分岐する構文は？|caseは複数のパターンに対する分岐に向く。
# 1.07 ネットワーク / プロトコル
TCP|順序制御・再送・接続確立を提供するトランスポート層プロトコルは？|TCPは信頼性のあるバイトストリームを提供する。
UDP|接続確立や再送をプロトコル自体で提供せず、データグラムを送信するトランスポート層プロトコルは？|UDPは軽量なデータグラム通信。信頼性が必要なら上位層で設計する。
ICMP|IPネットワークの到達性やエラー通知を扱い、pingでも利用されるプロトコルは？|ICMPは制御メッセージを扱う。TCP/UDPのポート番号は使用しない。
ARP|同一リンクのIPv4アドレスからMACアドレスを解決するプロトコルは？|ARPはIPv4とリンク層アドレスの対応を調べる。IPv6では近隣探索を利用する。
# 1.07 ネットワーク / ポート
22/TCP|SSHサーバーの標準的な待受ポートは？|SSHは既定でTCP 22を使用する。
25/TCP|SMTPでメールサーバー間の配送に通常使用するポートは？|SMTPのサーバー間配送は通常TCP 25。投稿用には587等がある。
53/UDP・TCP|DNSの通常の問い合わせやゾーン転送で利用するポートは？|DNSはUDPとTCPの53を利用する。
443/TCP|HTTP/1.1・HTTP/2 over TLSの標準ポートは？|TLS上のHTTPはTCP 443が標準。HTTP/3ではQUIC/UDPを使う。
80/TCP|暗号化しない通常のHTTP/1.1の標準ポートは？|HTTPの標準ポートはTCP 80。
123/UDP|NTPの時刻同期でサーバーが利用する標準ポートは？|NTPは通常UDP 123を使う。
# 1.07 ネットワーク / IPアドレス
192.168.0.0/16|次のうちRFC 1918で定義されるプライベートIPv4アドレス範囲は？|192.168.0.0〜192.168.255.255はプライベート用。
127.0.0.0/8|IPv4でループバックに予約される範囲は？|127.0.0.1などは自身のホスト内の通信に使う。
169.254.0.0/16|IPv4リンクローカルアドレスの範囲は？|同一リンクで利用する自動設定用範囲。
224.0.0.0/4|IPv4マルチキャスト用のアドレス範囲は？|224.0.0.0〜239.255.255.255はマルチキャスト。
# 1.07 ネットワーク / サブネット
255.255.255.0|IPv4の/24に対応するサブネットマスクは？|上位24ビットが1、下位8ビットが0。
255.255.255.192|IPv4の/26に対応するサブネットマスクは？|末尾オクテットの上位2ビットが1なので192。
255.255.0.0|IPv4の/16に対応するサブネットマスクは？|上位16ビットが1。
255.255.255.252|IPv4の/30に対応するサブネットマスクは？|末尾オクテットの上位6ビットが1なので252。
# 1.07 ネットワーク / 診断
ip addr show|Linuxのインターフェースに付与されたIPアドレスを確認したい。|ip addrはインターフェースのIPアドレスを扱う。
ip route show|現在のカーネルのIPルーティングテーブルを確認したい。|ip routeは経路の表示・変更を行う。
ss -lnt|TCPの待受ソケットを数値ポートで一覧確認したい。|-lはlisten、-nは数値表示、-tはTCP。
ping -c 4 192.0.2.1|指定IPv4へICMP Echoを4回送信し応答を確認したい。|-cは送信回数。応答がないことだけではホスト停止とは断定できない。
traceroute example.com|宛先までの中継ホップを調べたい。|TTL等を変化させ途中のルーターを推定する。
ip link show|ネットワークデバイスのリンク状態やMACアドレスを確認したい。|ip linkはリンク層のインターフェース情報を扱う。
# 1.07 ネットワーク / DNS
/etc/hosts|DNSに問い合わせずローカルファイルでホスト名とIPの対応を登録したい。|静的な名前解決の対応表。参照順序はnsswitch.conf等で決まる。
/etc/resolv.conf|一般的なLinuxのリゾルバが参照するDNSサーバー等の設定ファイルは？|nameserverやsearch等を記述する。環境によって自動生成される。
/etc/nsswitch.conf|ホスト名解決などでローカルファイルやDNSを参照する順序を設定したい。|Name Service Switchの設定ファイル。
dig example.com MX|example.comのメール配送先のDNSレコードをdigで照会したい。|MXはメール交換ホストを指定するDNSレコード。
# 1.08 システム管理 / アカウントファイル
/etc/passwd|ユーザー名、UID、GID、ホームディレクトリ、ログインシェル等が格納されるファイルは？|ユーザーの基本情報。通常パスワードハッシュはshadowに分離される。
/etc/shadow|ローカルユーザーのパスワードハッシュや有効期限が格納されるファイルは？|一般ユーザーには通常読み取り権限がない。
/etc/group|ローカルグループ名、GID、追加メンバーを定義するファイルは？|グループ情報を管理する。
/etc/skel|新規ユーザーのホームにコピーするひな形を配置するディレクトリは？|useradd -mなどの作成時に利用する。
# 1.08 システム管理 / ユーザー操作
useradd -m alice|aliceという新規ユーザーをホームディレクトリも含め作成したい。|-mはホームディレクトリを作成する。
usermod -aG docker alice|aliceの既存の補助グループを維持したままdockerグループを追加したい。|-aGの-aが重要。-Gのみでは指定されていない補助グループから外れる。
userdel -r alice|aliceを削除し、管理対象のホームとメールスプールも削除したい。|-rでホーム等も削除する。他の場所のファイルは別途確認する。
passwd -l alice|aliceのパスワードによるログインをロックしたい。|-lでパスワードをロックする。SSH公開鍵など他の認証方式は別途制限が必要。
id alice|aliceのUID、GIDと所属グループを確認したい。|idはユーザーとグループの識別情報を表示する。
# 1.08 システム管理 / ジョブ
crontab -e|現在のユーザーの定期ジョブ設定を編集したい。|-eでユーザーのcrontabを編集する。
crontab -l|現在のユーザーのcrontabの内容を表示したい。|-lは一覧表示。
at 23:00|今日または次回の23時に一度だけコマンドを実行する予約を登録したい。|atは一回限りの実行を予約する。
atq|atで登録した未実行ジョブを確認したい。|atqは保留中のatジョブを表示する。
# 1.08 システム管理 / cron
0 9 * * 1|毎週月曜日の午前9時にcronで実行したい。時刻部分は？|cronは分、時、日、月、曜日の順。曜日1は月曜日。
*/5 * * * *|5分おきにcronで実行したい。時刻部分は？|分フィールドのステップ指定で5分刻みになる。
0 0 1 * *|毎月1日の午前0時にcronで実行したい。時刻部分は？|日フィールドを1、時分を0にする。
30 18 * * 5|毎週金曜日の18時30分にcronで実行したい。時刻部分は？|分30、時18、曜日5は金曜日。
