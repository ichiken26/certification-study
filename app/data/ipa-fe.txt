# 01 基礎理論 / 数値表現
13|2進数1101を10進数にすると？|8+4+0+1=13。
10|2進数1010を10進数にすると？|8+0+2+0=10。
15|16進数Fを10進数にすると？|16進数のA〜Fは10〜15。
31|16進数1Fを10進数にすると？|1×16+15=31。
# 01 基礎理論 / 論理演算
AND|2入力が両方1のときだけ出力1となる論理演算は？|論理積。どちらかが0なら0。
OR|少なくとも1入力が1なら出力1となる論理演算は？|論理和。両方0のときだけ0。
XOR|2入力の値が異なるときだけ1になる論理演算は？|排他的論理和。01または10で1。
NAND|2入力が両方1のときだけ0となる論理演算は？|ANDの否定。00、01、10で1。
# 02 アルゴリズム / 計算量
O(log n)|ソート済み配列に対する二分探索の最悪時間計算量は？|探索範囲を毎回半分にするため対数オーダー。
O(n)|未ソート配列で先頭から目的値を順番に探す線形探索の最悪時間計算量は？|最悪で全要素を1回ずつ調べる。
O(n²)|n回のループの各回でn回の独立した処理を行う二重ループの時間計算量は？|合計n×n回の処理。
O(n log n)|典型的なマージソートの最悪時間計算量は？|分割はlog n段で各段のマージにO(n)かかる。
# 02 アルゴリズム / データ構造
スタック|最後に追加した要素を最初に取り出すLIFOのデータ構造は？|関数呼出しやUndo等に用いられる。
キュー|最初に追加した要素を最初に取り出すFIFOのデータ構造は？|処理待ちや幅優先探索などに利用する。
ハッシュテーブル|キーのハッシュ値を使って格納場所を決め、平均的に高速なキー検索を行うデータ構造は？|ハッシュ衝突への対処が必要。
ヒープ|最小値または最大値を効率よく取り出す優先度付きキューの実装に使われる木構造は？|親子間の順序条件を満たす。全要素がソート済みとは限らない。
# 03 データベース / SQL
GROUP BY|部署ごとに給与合計をSQLで集計したい。グループ化句は？|指定列の値ごとに行をまとめ集約関数を利用する。
HAVING|SQLで部署ごとの集計後、SUM(salary)が一定額以上のグループだけ残したい。|HAVINGは集約結果への条件。WHEREは通常集約前の行条件。
WHERE|SQLで集計前に対象行を条件で絞り込みたい。|WHEREは行に対する条件を記述する。
ORDER BY|SQLの結果を社員番号の昇順に並べ替えたい。|ORDER BYは結果セットの順序を指定する。
# 04 セキュリティ / 攻撃対策
プリペアドステートメント|入力値にSQL構文を混ぜ込まれるSQLインジェクションを防ぐDBアクセス方法は？|SQLと入力パラメータを分離する。
出力コンテキストに応じたエスケープ|Webページにユーザー入力を表示する際にXSSを防ぐ基本対策は？|HTML・属性等の出力先に合わせて特殊文字を適切に処理する。
CSRFトークン|認証済み利用者のブラウザから他サイト経由で意図しない状態変更要求を送られる攻撃の対策は？|要求にセッション等と結び付けた検証用トークンを含める。
多要素認証|パスワード漏洩だけでアカウントを奪われるリスクを減らす認証方式は？|異なる種類の認証要素を組み合わせる。
# 05 マネジメント / プロジェクト
WBS|プロジェクトの成果物や作業を階層的に分解して管理したい。|Work Breakdown Structure。作業範囲の整理に使う。
ガントチャート|作業ごとの開始・終了予定や進捗を横棒で可視化したい。|作業と時間軸の関係を視覚化する。
クリティカルパス|プロジェクト全体の最短完了時間を決定する依存作業の経路は？|余裕時間がない経路の遅延は全体完了に影響する。
EVM|計画価値、出来高、実コストを用いて進捗と費用を統合管理する手法は？|Earned Value ManagementでPV、EV、AC等を評価する。
# 06 ストラテジ / 経営
SWOT分析|強み・弱み・機会・脅威の4分類で経営環境を分析する手法は？|内部環境と外部環境を整理する。
PPM|市場成長率と相対的市場シェアで事業ポートフォリオを分析する手法は？|花形、金のなる木、問題児、負け犬等に分類する。
BSC|財務、顧客、内部業務、学習と成長の観点で戦略目標を管理する手法は？|Balanced Scorecard。財務以外の指標も扱う。
PEST分析|政治・経済・社会・技術のマクロ環境要因を整理する手法は？|外部環境の分析に利用する。
