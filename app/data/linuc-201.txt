# 2.01 起動とカーネル / カーネル管理
uname -r|稼働中のLinuxカーネルのリリース番号を表示したい。|uname -rはカーネルリリースを表示する。ディストリビューションのバージョンとは別。
modinfo e1000e|カーネルモジュールe1000eのファイル名や依存関係、パラメータを確認したい。|modinfoはモジュールのメタデータを表示する。
sysctl -w net.ipv4.ip_forward=1|稼働中のLinuxでIPv4転送を一時的に有効にしたい。|sysctlで/proc/sys配下のカーネルパラメータを変更する。永続化はsysctl.d等の設定。
depmod -a|インストール済みカーネルモジュールの依存関係情報を再生成したい。|depmodはmodules.dep等を作成しmodprobeが利用する。
# 2.01 起動とカーネル / GRUB
/etc/default/grub|ディストリビューションのGRUB生成ツールで既定カーネル引数などの共通設定を編集する代表的ファイルは？|GRUB構成生成の入力。生成されたgrub.cfgを直接編集しないのが一般的。
grub-mkconfig|GRUBの設定スクリプトからgrub.cfgを生成するコマンドは？|Debian系のupdate-grubはこの処理のラッパーとして使われる。
grub-install|指定デバイスにGRUBブートローダーを導入するコマンドは？|ブートローダーのインストールを行う。UEFI等で引数や手順は異なる。
/proc/cmdline|現在起動しているカーネルに渡された起動パラメータを確認するファイルは？|起動時のカーネルコマンドラインを確認できる。
# 2.02 ファイルシステム / LVM
pvcreate /dev/sdb|LVMで新しいディスクを物理ボリュームとして初期化したい。|PVを作る。既存データ破壊に注意。
vgcreate vg0 /dev/sdb|初期化済みPVからvg0というボリュームグループを作りたい。|VGは物理ボリュームをまとめる容量プール。
lvcreate -L 20G -n data vg0|vg0から20GiBの論理ボリュームdataを切り出したい。|LVを作成する。通常その後ファイルシステムを作る。
lvextend -r -L +10G /dev/vg0/data|対応ファイルシステムを持つLVとそのファイルシステムを10GiB拡張したい。|lvextend -rで論理ボリュームと対応FSを拡張する。
# 2.02 ファイルシステム / 修復・容量
xfs_growfs /mnt/data|マウント中のXFSで基盤のブロック容量を拡張済み。FSを拡張したい。|XFSはマウント状態でxfs_growfsにより拡張する。
resize2fs /dev/vg0/data|拡張したブロックデバイス上のext4ファイルシステムを拡張したい。|ext2/3/4のサイズ変更ツール。
xfs_repair /dev/vg0/data|アンマウントしたXFSファイルシステムの破損を修復したい。|XFS専用の修復ツール。通常マウントしたまま実行しない。
tune2fs -l /dev/sdb1|ext4のスーパーブロックや予約ブロックの情報を表示したい。|tune2fsはext系ファイルシステムのパラメータ確認・調整に使う。
# 2.03 ネットワーク構成 / コマンド
ip route add 192.0.2.0/24 via 10.0.0.1|Linuxの経路表に192.0.2.0/24宛を10.0.0.1経由で追加したい。|ip route addで指定ネットワークへの経路を追加する。
ip neigh show|Linuxがキャッシュした近隣ノードのIPとリンク層アドレスの対応を表示したい。|IPv4のARP、IPv6の近隣探索の情報を確認する。
tcpdump -ni eth0 port 443|eth0で443番ポートのパケットを名前解決せずキャプチャしたい。|tcpdumpはパケットを取得する。-nは名前解決を抑制する。
ethtool eth0|eth0のリンク速度・デュプレックスなどを確認したい。|Ethernetデバイスの設定・情報確認用。
# 2.03 ネットワーク構成 / 高度な構成
VLAN (802.1Q)|同じ物理スイッチ上でタグを付けて複数の論理L2ネットワークを分離したい。|VLANタグでブロードキャストドメインを分けられる。
Linux bridge|複数インターフェースをソフトウェアのL2スイッチとして接続したい。|LinuxブリッジはMACアドレス学習などによりL2転送を行う。
bonding|複数の物理NICを1つの論理インターフェースとして冗長化したい。|bondingはNICの集約・冗長化を提供する。モードによってスイッチ設定が必要。
ip rule|送信元IP等の条件で参照するルーティングテーブルを変えたい。|ポリシールーティングのルールを設定する。
# 2.04 保守・運用 / 監視
vmstat 1|1秒ごとにCPU・メモリ・スワップ・実行待ち等の概要を監視したい。|vmstatは仮想メモリとシステム統計を表示する。
iostat -x 1|ブロックデバイスのI/O待ち時間や利用率など詳細統計を継続監視したい。|iostat -xは拡張ディスクI/O統計を表示する。
sar|sysstatで収集済みの過去のCPUなどのシステム活動を調べたい。|sarは収集されたシステム統計を表示する。
free -h|利用可能メモリやスワップの概要を読みやすい単位で表示したい。|freeはメモリ使用状況の概要を表示する。availableにも注目する。
# 2.04 保守・運用 / 構築・バックアップ
make|Makefileの依存関係に従ってソースからビルドしたい。|makeはターゲットと依存関係を評価し必要な処理を実行する。
rsync -a src/ backup/|変更差分を転送しつつディレクトリの属性等を維持して同期したい。|rsyncは差分転送と同期を行う。末尾スラッシュの意味に注意。
tar -czf backup.tar.gz dir|ディレクトリをtarアーカイブにまとめgzip圧縮したい。|-cで作成、-zでgzip、-fでファイル名指定。
Ansible|SSH経由で多数サーバーの宣言的な構成をPlaybookで管理したい。|エージェントレスの構成管理・自動化ツール。
# 2.05 仮想化 / libvirt
virsh list --all|libvirt管理下の停止中も含むVMを一覧表示したい。|--allで稼働していないドメインも表示する。
virsh start vm1|定義済みの停止中VM vm1を起動したい。|startは既存ドメインを起動する。
virsh shutdown vm1|VM vm1に通常のシャットダウンを要求したい。|ゲストOSへ終了要求する。強制停止はdestroy。
virsh define vm.xml|VM定義XMLから永続的なドメイン定義を作りたい。|defineはVM定義を登録する。起動は別操作。
# 2.06 コンテナ / Docker
docker build -t app:1 .|カレントディレクトリのDockerfileからイメージapp:1を作成したい。|buildはイメージを構築する。-tでタグを付ける。
docker run -d -p 8080:80 nginx|nginxコンテナをバックグラウンドで起動し、ホスト8080をコンテナ80へ公開したい。|-dはデタッチ、-pはホストとコンテナのポート割当。
docker exec -it app sh|実行中のappコンテナで対話的なシェルを起動したい。|execは既存コンテナ内で新規プロセスを実行する。
docker logs -f app|appコンテナの標準出力・エラーのログを追従したい。|-fは新しいログを継続表示する。
