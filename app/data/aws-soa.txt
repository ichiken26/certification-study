# 01 モニタリング・復旧 / 運用
CloudWatch Agent|EC2内のOSメモリ使用率やディスク使用率をCloudWatchへ送信したい。|標準EC2メトリクスには通常OS内のメモリ等がないためエージェントで収集する。
CloudWatch Logs subscription filter|CloudWatch Logsのログイベントを継続的にLambda等へ転送して処理したい。|サブスクリプションフィルターはログのストリーミング配送を設定する。
CloudWatch anomaly detection|一定閾値では検知しにくい日周期の異常なメトリクス値を監視したい。|過去のパターンに基づく期待値帯をモデル化して異常を検知できる。
AWS Health Dashboard|利用中のAWSリソースに影響するAWS側のメンテナンス・障害情報を確認したい。|アカウントに関連するAWS Healthイベントを確認する。
# 02 信頼性・可用性 / 復旧
EC2 Auto Recovery|対応EC2で基盤ハードウェア障害時にインスタンスを回復させたい。|対応構成のインスタンスを正常なホストへ回復する。アプリの冗長化とは別。
AWS Backup Vault Lock|バックアップボールトの保持期間を保護し、誤削除や変更を制限したい。|ボールトロックで保持ポリシーを強制できる。
Route 53 Failover routing|プライマリの公開エンドポイントに障害が発生したらDNSでセカンダリへ切り替えたい。|ヘルスチェックなどと組み合わせたDNSフェイルオーバー。
EBSスナップショット|EC2ボリュームの内容をバックアップから別AZのボリュームに復元したい。|スナップショットを元に対象AZでボリュームを作成する。
# 03 デプロイ・自動化 / Systems Manager
Patch Manager|多数のEC2にOSパッチを基準・スケジュールに従って適用したい。|パッチベースラインと運用設定でパッチを管理する。
Run Command|管理対象EC2のグループに同じシェルコマンドを一括で実行したい。|SSMドキュメントを指定してコマンドを実行する。
Session Manager|EC2にSSHポートを公開せず、IAMで管理接続したい。|SSM Agent等を用いて管理セッションを提供する。
State Manager|複数の管理対象ノードが継続的に指定の構成状態となるよう関連付けを管理したい。|設定した関連付けをスケジュール等に従って適用する。
# 04 セキュリティ・ネットワーク / 調査
Reachability Analyzer|VPC内でENIから別リソースへ特定プロトコルで到達可能か、設定上の経路を解析したい。|構成に基づく静的な到達性分析。実パケットは送信しない。
VPC Flow Logs|特定ENIで通信がACCEPT/REJECTされたフロー情報を確認したい。|ネットワークフローのメタデータを記録する。
AWS Config|あるSGの構成がいつ変更され、過去にどの設定だったかを追跡したい。|リソース構成履歴を記録する。
CloudTrail|誰がAuthorizeSecurityGroupIngressを呼び出したか調べたい。|API呼び出しの主体・時刻・操作等を確認できる。
